The verb `tar` means "to come" and is one of the eleven irregular verbs in Irish. It is highly irregular, using several different stems depending on the tense and mood. The main stems are `tag-` for the present, `tháinig` for the past, and `tioc-` for the future and conditional. The verb root `tar` is used for the 2nd person singular imperative.

## Indicative Mood

### Present Tense

The present tense uses the stem `tag-`.

*Tagann an bus gach maidin.* - The bus comes every morning.

| Person | Form |
| --- | --- |
| 1st sg. | `tagaim` |
| 2nd sg. | `tagann tú` |
| 3rd sg. | `tagann sé/sí` |
| 1st pl. | `tagaimid` |
| 2nd pl. | `tagann sibh` |
| 3rd pl. | `tagann siad` |
| Autonomous | `tagtar` |
| Relative | `a thagas` |

### Past Tense (Preterite)

The past tense uses the unique stem `tháinig`.

*Tháinig mé abhaile go déanach.* - I came home late.

| Person | Form |
| --- | --- |
| 1st sg. | `thánag` |
| 2nd sg. | `tháingís` |
| 3rd sg. | `tháinig sé/sí` |
| 1st pl. | `thángamar` |
| 2nd pl. | `thángabhair` |
| 3rd pl. | `thángadar` |
| Autonomous | `thángthas` |

### Imperfect Tense

The imperfect tense, used for habitual past actions, uses the stem `thag-`.

*Thagainn anseo go minic nuair a bhí mé óg.* - I used to come here often when I was young.

| Person | Form |
| --- | --- |
| 1st sg. | `thagainn` |
| 2nd sg. | `thagtá` |
| 3rd sg. | `thagadh sé/sí` |
| 1st pl. | `thagaimis` |
| 2nd pl. | `thagadh sibh` |
| 3rd pl. | `thagaidís` |
| Autonomous | `thagtaí` |

### Future Tense

The future tense uses the stem `tioc-`.

*Tiocfaidh an samhradh go luath.* - The summer will come soon.

| Person | Form |
| --- | --- |
| 1st sg. | `tiocfad` |
| 2nd sg. | `tiocfaidh tú` |
| 3rd sg. | `tiocfaidh sé/sí` |
| 1st pl. | `tiocfaimid` |
| 2nd pl. | `tiocfaidh sibh` |
| 3rd pl. | `tiocfaidh siad` |
| Autonomous | `tiocfar` |
| Relative | `a thiocfas` |

## Conditional Mood

The conditional mood also uses the stem `tioc-`.

*Thiocfainn dá mbeadh am agam.* - I would come if I had time.

| Person | Form |
| --- | --- |
| 1st sg. | `thiocfainn` |
| 2nd sg. | `thiocfá` |
| 3rd sg. | `thiocfadh sé/sí` |
| 1st pl. | `thiocfaimis` |
| 2nd pl. | `thiocfadh sibh` |
| 3rd pl. | `thiocfaidís` |
| Autonomous | `thiocfaí` |

## Imperative Mood

The imperative mood uses the root `tar` for the 2nd person singular and the stem `tag-` for other forms.

*Tar anseo!* - Come here!

| Person | Form |
| --- | --- |
| 2nd sg. | `tar` |
| 3rd sg. | `tagadh sé/sí` |
| 1st pl. | `tagaimis` |
| 2nd pl. | `tagaigí` |
| 3rd pl. | `tagaidís` |
| Autonomous | `tagtar` |

## Subjunctive Mood

The subjunctive mood uses the stem `tag-`.

### Present Subjunctive

*Go dtaga an t-ádh leat.* - May luck come with you.

| Person | Form |
| --- | --- |
| 1st sg. | `go dtaga mé` |
| 2nd sg. | `go dtaga tú` |
| 3rd sg. | `go dtaga sé/sí` |
| 1st pl. | `go dtagaimid` |
| 2nd pl. | `go dtaga sibh` |
| 3rd pl. | `go dtaga siad` |
| Autonomous | `go dtagtar` |

### Past Subjunctive

*Dá dtagadh sé, bheadh áthas orm.* - If he were to come, I would be happy.

| Person | Form |
| --- | --- |
| 1st sg. | `dá dtagainn` |
| 2nd sg. | `dá dtagtá` |
| 3rd sg. | `dá dtagadh sé/sí` |
| 1st pl. | `dá dtagaimis` |
| 2nd pl. | `dá dtagadh sibh` |
| 3rd pl. | `dá dtagaidís` |
| Autonomous | `dá dtagtaí` |

## Dialectal Variations and Notes

<Dialect region="Connacht">
In Connemara, the imperative `teara` is often used instead of `tar`, and the present tense stem is `teag-` instead of `tag-`.
</Dialect>

<Dialect region="Ulster">
In Ulster Irish, the present tense stem is often `tig` instead of `tag-`. In the 3rd person, this form is uninflected: *tig sé* (he comes).
</Dialect>

<Dialect region="Ulster, Connacht">
In Ulster and parts of Connacht, the past tense of `tar` does not use the standard preterite particles `ar`, `níor`, and `gur`. Instead, the forms are based on the positive form `tháinig`.

| Standard | Ulster/Connacht | Meaning |
| --- | --- | --- |
| *Ar tháinig sé?* | *An dtáinig sé?* | Did he come? |
| *Níor tháinig sé.* | *Ní tháinig sé.* | He did not come. |
| *Dúirt mé gur tháinig sé.* | *Dúirt mé go dtáinig sé.* | I said that he came. |

</Dialect>

<Dialect region="Munster">
In Munster, synthetic forms (where the pronoun is included in the verb ending) are common in the past tense.

| Person | Munster Form(s) | Standard Analytic Form |
| --- | --- | --- |
| 1st sg. | `thángas`, `thánag`, `thánas`, `thána` | `tháinig mé` |
| 2nd sg. | `thán(g)ais`, `tháinis` | `tháinig tú` |
| 1st pl. | `thánamair` | `thángamar` |
| 2nd pl. | `thán(g)abhair` | `tháinig sibh` |
| 3rd pl. | `thán(g)adar` | `tháinig siad` |

The forms with `-ng-` are closer to the standard, but in spoken Munster Irish, a simple `-n-` is more common (e.g., `thánamair` instead of `thángamar`).
</Dialect>

<Note>
**Pronunciation:**
- `tháinig` is often pronounced with a hard 'c' sound at the end in Ulster and Connacht, as if spelled "tháinic" (`[ha:n′ək′]`).
- In `thángamar` (`[ha:nəgəmər]`) and `thángthas` (`[ha:nəkəs]`), the `ng` is pronounced as two separate sounds, `[n]` and `[g]`, separated by a short vowel, not as the single velar nasal sound found in words like `teanga`.
</Note>

<Details summary="Historical note on 'go dtí'">
The old 2nd/3rd person present subjunctive form `tí` is preserved in the common preposition `go dtí` (to, until). It is rarely seen with other conjunctions, but can appear in phrases like *sula dtí maidin* (before morning).
</Details>
