The verb `feic` means "to see" and is one of the eleven irregular verbs in Irish. Its irregularity is most prominent in the past tense, where it uses completely different stems for independent (`chonaic`) and dependent (`faca`) forms. Unlike regular verbs, it does not use the particle `d'`.

## Present Tense

The present tense uses the stem `feic-`.

| Person | Form |
| --- | --- |
| 1st sg. | `feicim` |
| 2nd sg. | `feiceann tú` |
| 3rd sg. | `feiceann sé/sí` |
| 1st pl. | `feicimid` |
| 2nd pl. | `feiceann sibh` |
| 3rd pl. | `feiceann siad` |
| Autonomous | `feictear` |
| Relative | `a fheiceas` |

- *Feicim an teach mór.* - I see the big house.

## Past Tense (Preterite)

The past tense has two distinct stems. The independent stem `chonaic` is used for positive statements. The dependent stem `faca` is used for negative statements and questions.

<Note>
Unlike regular verbs, `feic` does not take the preterite particle `d'` or `d'fh` in any form. The independent form begins with `ch-` and the dependent form begins with `fh-` or `bh-`.
</Note>

### Independent Forms

Use the stem `chonaic-` for positive statements.

| Person | Form |
| --- | --- |
| 1st sg. | `chonaiceas`, `chonac` |
| 2nd sg. | `chonaicís` |
| 3rd sg. | `chonaic sé/sí` |
| 1st pl. | `chonaiceamar` |
| 2nd pl. | `chonaiceabhair` |
| 3rd pl. | `chonaiceadar` |
| Autonomous | `chonacthas` |

- *Chonaic mé an scannán inné.* - I saw the film yesterday.

### Dependent Forms

Use the stem `faca-` after particles like `ní` (not), `an` (question), `go` (that), and `a` (relative).

| Person | Negative (`ní`) | Question (`an`) |
| --- | --- | --- |
| 1st sg. | `ní fhacas`, `ní fhaca` | `an bhfacas`, `an bhfaca` |
| 2nd sg. | `ní fhacaís` | `an bhfacaís` |
| 3rd sg. | `ní fhaca sé/sí` | `an bhfaca sé/sí` |
| 1st pl. | `ní fhacamar` | `an bhfacamar` |
| 2nd pl. | `ní fhacabhair` | `an bhfacabhair` |
| 3rd pl. | `ní fhacadar` | `an bhfacadar` |
| Autonomous | `ní fhacthas` | `an bhfacthas` |

- *Ní fhaca mé an scannán.* - I did not see the film.
- *An bhfaca tú an scannán?* - Did you see the film?

## Imperfect Tense

The imperfect tense describes habitual or repeated actions in the past. It uses the stem `d'fheic-`.

| Person | Form |
| --- | --- |
| 1st sg. | `d'fheicinn` |
| 2nd sg. | `d'fheicteá` |
| 3rd sg. | `d'fheiceadh sé/sí` |
| 1st pl. | `d'fheicimis` |
| 2nd pl. | `d'fheiceadh sibh` |
| 3rd pl. | `d'fheicidís` |
| Autonomous | `d'fheictí` |

- *D'fheicinn é gach lá.* - I used to see him every day.

## Future Tense

The future tense uses the stem `feicf-`.

| Person | Form |
| --- | --- |
| 1st sg. | `feicfead` |
| 2nd sg. | `feicfidh tú` |
| 3rd sg. | `feicfidh sé/sí` |
| 1st pl. | `feicfimid` |
| 2nd pl. | `feicfidh sibh` |
| 3rd pl. | `feicfidh siad` |
| Autonomous | `feicfear` |
| Relative | `a fheicfeas` |

- *Feicfidh mé thú amárach.* - I will see you tomorrow.

## Conditional Mood

The conditional mood uses the stem `d'fheicf-`.

| Person | Form |
| --- | --- |
| 1st sg. | `d'fheicfinn` |
| 2nd sg. | `d'fheicfeá` |
| 3rd sg. | `d'fheicfeadh sé/sí` |
| 1st pl. | `d'fheicfimis` |
| 2nd pl. | `d'fheicfeadh sibh` |
| 3rd pl. | `d'fheicfidís` |
| Autonomous | `d'fheicfí` |

- *D'fheicfinn an cluiche dá mbeadh ticéad agam.* - I would see the match if I had a ticket.

## Imperative Mood

The imperative is used for commands.

| Person | Form |
| --- | --- |
| 2nd sg. | `feic` |
| 3rd sg. | `feiceadh sé/sí` |
| 1st pl. | `feicimis` |
| 2nd pl. | `feicigí` |
| 3rd pl. | `feicidís` |
| Autonomous | `feictear` |

- *Feic!* - See!

## Subjunctive Mood

The subjunctive is used in certain clauses, often expressing wishes, possibilities, or conditions.

### Present Subjunctive

| Person | Form |
| --- | --- |
| 1st sg. | `go bhfeice mé` |
| 2nd sg. | `go bhfeice tú` |
| 3rd sg. | `go bhfeice sé/sí` |
| 1st pl. | `go bhfeicimid` |
| 2nd pl. | `go bhfeice sibh` |
| 3rd pl. | `go bhfeice siad` |
| Autonomous | `go bhfeictear` |

- *Go bhfeice an Tiarna thú.* - May the Lord see you.

### Past Subjunctive

| Person | Form |
| --- | --- |
| 1st sg. | `dá bhfeicinn` |
| 2nd sg. | `dá bfeicteá` |
| 3rd sg. | `dá bhfeiceadh sé/sí` |
| 1st pl. | `dá bhfeicimis` |
| 2nd pl. | `dá bhfeiceadh sibh` |
| 3rd pl. | `dá bhfeicidís` |
| Autonomous | `dá bhfeictí` |

- *Dá bhfeicinn an madra, rithfinn.* - If I were to see the dog, I would run.

## Verbal Noun and Adjective

| Form | Irish |
| --- | --- |
| **Verbal Noun** | `feiceáil` |
| **Genitive of Verbal Noun** | `feiceála` |
| **Verbal Adjective** | `feicthe` |

- *Tá mé ag feiceáil na farraige.* - I am looking at (seeing) the sea.
- *Tá an litir feicthe agam.* - I have seen the letter.

<Details summary="Historical note on older forms">
Historically, there was a distinction between absolute forms (used in simple positive statements) and dependent forms (used after particles). The verb `feic` originally used the stem `(do-)chí-` for its absolute forms and `feic-` only for its dependent forms.

| Tense | Dependent | Absolute (Older) |
| --- | --- | --- |
| **Present** | `feiceann` | `(do-)chíonn` |
| **Imperfect** | `feiceadh` | `(do-)chíodh` |
| **Future** | `feicfidh` | `(do-)chífidh` |
| **Conditional** | `feicfeadh` | `(do-)chífeadh` |

This distinction is now mostly lost in Standard Irish and in the Connacht dialect, where `feic-` is used for both. However, the `(do-)chí-` forms are still common in Munster and Ulster dialects.
</Details>

## Dialectal Variations

<Dialect region="Ulster">
In Ulster, the absolute present tense form is often `tí sé` or `tchí sé` ("he sees"), while the dependent form remains `ní fheiceann sé`. The autonomous form can be `títear`, `tchítear`, or `tíotar`. This pattern of using `tí-`/`tchí-` for absolute forms and `feic-` for dependent forms continues in the future, imperfect, and conditional tenses.

- **Future:** `tíofaidh sé` (absolute) vs. `ní fheicfidh sé` (dependent).
- **Conditional:** `tífeadh sé` or `thiúfadh sé` (absolute) vs. `ní fheicfeadh sé` (dependent).
- **Preterite:** The independent form is `chonnaic`, and the dependent is `ní fhacaidh`.
- **Imperative:** Instead of `feic`, speakers often use `amharc!` or `dearc!`.
- **Verbal Noun:** `feiceáil` or `feiceáilt`.
- **Verbal Adjective:** `feicthe` or `feiciste`.
</Dialect>

<Dialect region="Connacht">
The forms in Connacht largely match the Standard. Some variations include:
- **Autonomous Present:** Alongside `feictear`, you may hear `feicthear`, `feicthears`, or `feictheas`. The form `chítear` appears mainly in the idiom `chítear dhom` ("it seems to me").
- **Preterite:** The form `choinic` or `chainic` is often used instead of `chonaic`. This can sometimes also be used as a dependent form (`níor choinic`). The autonomous form `facthas` or `facthús` can be used for both absolute and dependent contexts.
</Dialect>

<Dialect region="Munster">
In some parts of Munster (e.g., Dingle), the verb is regularised with the stem `cí-` for most tenses (e.g., `cíonn sé` for absolute, `ní chíonn sé` for dependent).

In other areas:
- **Present:** `chíonn sé` (absolute) vs. `ní fhiceann sé` (dependent).
- **Future:** `chífidh` (absolute) vs. `ní fhicfidh` (dependent).
- **Preterite:** The independent form is often shortened to `(do) chnuc` (from `chonac`), e.g., `chnuic sé`. The dependent form is `ní fheacaidh`. The particle `ní` often contracts to `n'` before `fh-`, as in `n'fhiceann sé`.
- **Verbal Noun:** `fiscint`.
- **Verbal Adjective:** `ficithe`, `feicithe`, or `fiscithe`.
</Dialect>
