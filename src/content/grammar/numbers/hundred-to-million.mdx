Irish uses a clear, component-based system for forming large numbers. Once you know the words for "hundred" (`céad`), "thousand" (`míle`), and "million" (`milliún`), you can construct larger values by combining them with the numbers from 1-99. This page covers the three main types of numbers: abstract (`maoluimhreacha`), cardinal (`bunuimhreacha`), and ordinal (`orduimhreacha`).

## Abstract Numbers (Maoluimhreacha)

Abstract numbers, or `maoluimhreacha`, are used for counting without referring to a specific noun, like saying "one, two, three..." or reading out a year. The structure for numbers over 100 often uses `a` to connect the parts.

*   *céad a haon* - one hundred and one
*   *míle naoi gcéad seasca a hocht* - one thousand, nine hundred and sixty-eight (the year 1968)

| Number | Irish Form |
| :--- | :--- |
| 100 | `céad` |
| 101 | `céad a haon` |
| 102 | `céad a dó` |
| 120 | `céad is fiche` |
| 123 | `céad fiche a trí` |
| 200 | `dhá chéad` |
| 700 | `seacht gcéad` |
| 1,000 | `míle` |
| 1,001 | `míle a haon` |
| 1,968 | `míle naoi gcéad seasca a hocht` |
| 2,000 | `dhá mhíle` |
| 10,000 | `deich míle` |
| 100,000 | `céad míle` |
| 1,000,000 | `milliún` |
| 1,002,305 | `milliún, dhá mhíle, trí chéad a cúig` |

## Cardinal Numbers (Bunuimhreacha)

Cardinal numbers, or `bunuimhreacha`, are used to count nouns like people or objects. The structure is slightly different from abstract numbers, often using `is` ("and") to connect the number to the noun.

*   *céad bád* - one hundred boats
*   *céad is dhá bhád* - one hundred and two boats

### Grammar Rules

1.  **Noun Form:** After `céad`, `míle`, and `milliún`, the noun that follows stays in the singular. For example, `céad bád` (100 boats), not `*céad báid`.
2.  **Connecting with `is`:** For numbers like 101, 102, etc., the word `is` ("and") is used before the noun. For example, *céad is bád* means "101 boats".
3.  **Mutations:** The final digit of the number determines the mutation of the following noun, following the standard rules for numbers 1-19.
    *   **Lenition:** after `dhá` (two). e.g., *céad is dhá **bh**ád* (102 boats).
    *   **Eclipsis:** after `seacht`, `ocht`, `naoi`, `deich` (7, 8, 9, 10). e.g., *céad is seacht **mb**ád* (107 boats).

<Tip>
The structure `(larger number) is (smaller number + noun)` is very consistent. For 123 boats, you say `céad fiche is trí bhád`, which is like "hundred twenty and three boats".
</Tip>

<Note>
Some nouns, particularly units of time like `bliain` (year), use the genitive plural after numbers 3–10 and 13–19. This is why you see `seacht mbliana` (seven years) instead of `*seacht mbliain`.
</Note>

### Examples

| Number | Counting "boats" (`bád`) | Counting "years" (`bliain`) |
| :--- | :--- | :--- |
| 100 | `céad bád` | `céad bliain` |
| 101 | `céad is bád` | `céad is bliain` |
| 102 | `céad is dhá bhád` | `céad is dhá bhliain` |
| 107 | `céad is seacht mbád` | `céad is seacht mbliana` |
| 110 | `céad is deich mbád` | `céad is deich mbliana` |
| 112 | `céad is dhá bhád déag` | `céad is dhá bhliain déag` |
| 120 | `céad is fiche bád` | `céad is fiche bliain` |
| 200 | `dhá chéad bád` | `dhá chéad bliain` |
| 700 | `seacht gcéad bád` | `seacht gcéad bliain` |
| 1,000 | `míle bád` | `míle bliain` |
| 2,000 | `dhá mhíle bád` | `dhá mhíle bliain` |
| 1,000,000 | `milliún bád` | `milliún bliain` |

## Ordinal Numbers (Orduimhreacha)

Ordinal numbers indicate position in a sequence (e.g., "first", "second", "hundredth"). In Irish, they are formed by adding a suffix, usually `-ú`, to the cardinal number and are preceded by the definite article `an`.

*   *an chéadú bád* - the 100th boat
*   *an míliú bád* - the 1000th boat

### Grammar Rules

1.  **The Suffix `-ú`:** The ending `-ú` is added to the number to make it ordinal. For numbers ending in a vowel, this may be adjusted, for example, `fiche` becomes `fichiú`.
2.  **The Definite Article `an`:** Ordinal numbers are almost always used with `an`. This causes lenition where applicable (e.g., `céad` -> `an chéadú`) and adds a t-prefix before a vowel (e.g., `ocht` -> `an t-ochtú`).
3.  **Compound Ordinals:** For numbers like 101st, the structure is `an (larger number) is (smaller ordinal)`. For example, *an céad is aonú bád* (the 101st boat).

### Examples

| Number | Ordinal Form (with `bád`) | Abbreviation |
| :--- | :--- | :--- |
| 100th | `an chéadú bád` | 100ú |
| 101st | `an céad is aonú bád` | 101ú |
| 102nd | `an céad is dóú bád` | 102ú |
| 107th | `an céad is seachtú bád` | 107ú |
| 110th | `an céad is deichiú bád` | 110ú |
| 120th | `an céad is fichiú bád` | 120ú |
| 200th | `an dá chéadú bád` | 200ú |
| 800th | `an t-ocht gcéadú bád` | 800ú |
| 1,000th | `an míliú bád` | 1,000ú |
| 2,000th | `an dá mhíliú bád` | 2,000ú |
| 1,000,000th | `an milliúnú bád` | 1,000,000ú |

## Very Large Numbers

The system extends logically for even larger numbers.

| Number | English Term | Irish Term |
| :--- | :--- | :--- |
| 1,000,000 | Million | `milliún` |
| 1,000,000,000 | Billion (long scale) | `míle milliún` |
| 1,000,000,000,000 | Trillion (long scale) | `billiún` |

<Note>
Traditionally, Irish uses the "long scale" system for large numbers, where a billion is a million million (10<sup>12</sup>). However, due to influence from American English, you may sometimes hear `billiún` used to mean one thousand million (10<sup>9</sup>), which is the "short scale" billion. The term `míle milliún` is unambiguous for 10<sup>9</sup>.
</Note>
