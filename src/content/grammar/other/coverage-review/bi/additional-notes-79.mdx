This page documents non-standard conjugations of the verb `bí` (to be), which are still used in some Munster dialects. Many of these forms include the preverbal particle `do`, which is now generally omitted in the Standard Language.

## Munster Dialect Conjugations

### Indicative Mood

| Person | Present | Past | Imperfect (Habitual Past) | Future |
| :--- | :--- | :--- | :--- | :--- |
| 1st sg. | `táim` | `do bhíos` | `do bhínn` | `bead` |
| 2nd sg. | `tá(nn) tú`, `tás tú`, `táir`, `taoi` | `do bhís` | `do bhíteá` | `beir` |
| 3rd sg. | `tá sé` | `do bhí sé` | `do bhíodh sé` | `beidh sé` |
| 1st pl. | `táimid` | `do bhíomair` | `do bhímis` | `beimid` |
| 2nd pl. | `tá(nn) sibh`, `tathaoi` | `do bhíobhair` | `do bhíodh sibh` | `beidh sibh`, `beithí` |
| 3rd pl. | `táid` | `do bhíodar` | `do bhídís` | `beid` |
| Autonomous | `táthar`, `táthars` | `do bhíothas` | `do bhítí` | `beifear` |

### Conditional Mood

The conditional mood can be formed with the particle `do` or with the conjunction `dá` ('if').

| Person | Conditional with `do` | Conditional with `dá` |
| :--- | :--- | :--- |
| 1st sg. | `do bheinn` | `dá mbínn` |
| 2nd sg. | `do bheifeá` | `dá mbíteá` |
| 3rd sg. | `do bheadh sé` | `dá mbíodh sé` |
| 1st pl. | `do bheimis` | `dá mbímis` |
| 2nd pl. | `do bheadh sibh` | `dá mbíodh sibh` |
| 3rd pl. | `do bheidís` | `dá mbídís` |
| Autonomous | `do bheifí` | `dá mbítí` |

| Person | Present Subjunctive | Past Subjunctive |
| :--- | :--- | :--- |

| 2nd sg. | `go raibhir` | `go mbír` |

## Habitual and Dependent Forms

### Habitual Present

| Person | Form |
| :--- | :--- |
| 1st sg. | `bím` |
| 2nd sg. | `bíonn tú`, `bír` |
| 3rd sg. | `bíonn sé` |
| 1st pl. | `bímid` |
| 2nd pl. | `bíonn sibh`, `bíthí` |
| 3rd pl. | `bíd` |
| Autonomous | `bítear` |

### Dependent Forms

These forms are used after particles like `an`, `ní`, `go`, `nach`, `ná`, and `a`.

| Person | Present Interrogative (`an`) | Present Negative (`ní`) | Present Negative Interrogative (`ná`) | Past Dependent (`an`) |
| :--- | :--- | :--- | :--- | :--- |
| 1st sg. | `an bhfuilim` | `nílim` | `ná fuilim` | `an rabhas` |
| 2nd sg. | `an bhfuil(eann) tú`, `an bhfuilir` | `níl(eann) tú`, `nílir` | `ná fuil(eann) tú`, `ná fuilir` | `an rabhais` |
| 3rd sg. | `an bhfuil sé` | `níl sé` | `ná fuil sé` | `an raibh sé` |
| 1st pl. | `an bhfuilimid` | `nílimid` | `ná fuilimid` | `an rabhamair` |
| 2nd pl. | `an bhfuil(eann) sibh`, `an bhfuiltí` | `níl(eann) sibh`, `níltí` | `ná fuil(eann) sibh`, `ná fuiltí` | `an rabhabhair` |
| 3rd pl. | `an bhfuilid` | `nílid` | `ná fuilid` | `an rabhadar` |
| Autonomous | `an bhfuiltear` | `níltear` | `ná fuiltear` | `an rabhthas` |

## Further Dialect Notes

- **Pronunciation**: The forms of `tá` are always pronounced as `thá` [hɑː] in the Ring (An Rinn, Co. Waterford) dialect, and sometimes in West Munster.
- **Present Tense `-nn`**: The ending `-nn` in the present tense dependent forms (`fuileann`, `níleann`) is found only in the 2nd person singular and plural.
- **Negative Interrogative `ná`**: In Munster (except Waterford), the particle `ná` is used instead of `nach` as a negative interrogative particle (e.g., *Are you not?*). This `ná` causes neither lenition nor eclipsis.
